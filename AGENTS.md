# AGENTS.md

## Code Philosophy

- Prioritize readability, simplicity, and maintainability over cleverness.
- Write concise, self-explanatory code. Prefer clarity over brevity when they conflict.
- Follow existing project conventions and patterns.
- Avoid premature abstractions, unnecessary indirection, and overengineering.
- Prefer small, focused functions with descriptive names.
- Keep changes minimal and scoped to the task at hand.
- Avoid introducing dependencies unless they provide clear value.

## Comments & Documentation

- Code should be self-documenting whenever possible.
- Keep documentation concise and focused on information that cannot be easily inferred from the code.
- Update existing documentation when behavior or interfaces change and invaliates documentation.

## Implementation

- Prefer straightforward solutions over elaborate designs.
- Reuse existing functionality before introducing new abstractions.
- Handle errors explicitly and consistently with project conventions.
- Avoid unrelated refactoring or formatting changes.
- Write tests for meaningful behavior and edge cases, following existing testing patterns.
- Do not introduce speculative functionality or compatibility layers without a concrete need.
